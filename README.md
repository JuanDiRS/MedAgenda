<h2>Agenda medica</h2>
<p>En este repositorio se encuentra un proyecto que consiste en el desarrollo de una agenda médica. En esta plataforma, pacientes y doctores pueden interactuar para agendar citas médicas y gestionarlas de acuerdo con la disponibilidad del doctor.
  Además, cuenta con un servicio administrativo encargado de la gestión general de la agenda.</p>
